## 1. Platform Overview & Navigation

The platform provides a unified operations dashboard accessible via your browser (`http://localhost:8501`). All primary investigation modules are selectable from the dark-themed sidebar on the left.

### Key Operational Philosophy
- **Defanging by Default:** All indicators are safely defanged (`194[.]26[.]29[.]112`, `hxxp://evil[.]com`) in headers and report tables to prevent accidental execution.
- **Zero-Key Operational Readiness:** If commercial API keys are unavailable, the platform automatically leverages its local signature database, live DNS resolution, WHOIS/RDAP queries, and machine learning models.
- **Explainable Metrics:** Every risk score provides an itemized list of exact points added and the evidentiary source.

## 2. Module 1: Threat Overview Dashboard
The Executive Dashboard presents real-time threat metrics:
- **Total Indicators Analyzed:** Aggregate historical database record count.
- **Confirmed Malicious:** Indicators rated High or Critical ($\ge 70/100$).
- **Suspicious:** Indicators with elevated heuristic or community flags ($30–69/100$).
- **Low Risk:** Clean traffic or authorized testing infrastructure ($< 30/100$).
- **Quick Lookup:** Submit any IP, domain, URL, or hash. The engine automatically determines the type, refangs it if necessary, and renders a risk gauge and executive brief.

## 3. Module 2: IP Address Intelligence
Investigate public or private IP addresses:
1. Select **IP Intelligence** from the sidebar.
2. Enter an IPv4 (`194.26.29.112`) or IPv6 address (`2001:db8::1`).
3. Check **Bypass Cache** if you require a fresh non-cached lookup.
4. Review:
   - **Scope:** Public routable or private internal (RFC 1918 / Loopback).
   - **Geolocation & Network:** Country, ISP, Autonomous System (ASN).
   - **Reverse DNS:** Active PTR hostnames associated with the IP.
   - **Provider Breakdown:** Detections from VirusTotal, AbuseIPDB, and AlienVault OTX.
   - **SOC Countermeasures:** Specific firewall blocking and SIEM search recommendations.

## 4. Module 3: Domain Intelligence & DNS Analysis
Analyze suspicious domains:
1. Select **Domain Intelligence**.
2. Enter a domain (e.g., `malicious-payload-cdn.net` or `paypa1.com`).
3. Inspect:
   - **Live DNS Records:** Resolved A, AAAA, MX, NS, TXT, and CNAME records.
   - **DGA Classifier:** Machine learning assessment indicating whether the domain was generated by a botnet algorithm (evaluates Shannon entropy and consonant density).
   - **Typosquatting Alerts:** Checks Levenshtein edit distance against top brands (Google, Microsoft, PayPal, Amazon, etc.).
   - **WHOIS/RDAP:** Domain creation, expiration, and registrar handle.

## 5. Module 4: URL Intelligence & SSRF-Safe Probe
Inspect suspicious links without compromising your workstation:
1. Select **URL Intelligence**.
2. Input a URL (e.g., `hxxp://evil-site[.]com/login.php?user=admin`).
3. The platform performs an **SSRF-Protected HTTP HEAD Probe**:
   - Blocks any URL resolving to a private, loopback, or cloud metadata IP (`169.254.169.254`).
   - Follows up to 3 redirects, validating each hop.
   - Collects status codes, content types, and server banners without rendering HTML or JavaScript.
4. **Phishing Lexical Classifier:** Flags suspicious keywords (`login`, `verify`, `banking`), bare IPs, and `@` delimiters.

## 6. Module 5: File Hash Intelligence & In-Memory Uploads
Investigate malware samples:
- **Hash Lookup Tab:** Enter MD5 (32 chars), SHA-1 (40 chars), or SHA-256 (64 chars). The engine queries local signatures (e.g., WannaCry, LockBit, Emotet) and external feeds.
- **Safe File Upload Tab:** Upload any suspicious file up to 50MB. The engine streams the file in 64KB chunks in-memory, computes MD5, SHA-1, and SHA-256 hashes, and identifies file format via magic byte headers. **The file is never executed or written to disk as executable code.**

## 7. Module 6: IOC Extraction, Refanging & Defanging
Process raw unstructured text:
1. Paste emails, incident tickets, or chat logs containing defanged indicators (e.g., `hxxps://bad[.]org/payload[.]exe`, `10[.]0[.]0[.]1`).
2. Click **Extract & Categorize IOCs**.
3. The engine automatically refangs, validates, normalizes, deduplicates, and categorizes indicators into IPs, Domains, URLs, and Hashes.
4. Download the extracted indicators as clean CSV or JSON.

---

## 8. Module 7: Batch IOC Analysis
Perform high-throughput triage:
1. Paste up to 50 indicators (one per line) or upload a `.txt` or `.csv` file.
2. Click **Start Batch Analysis**.
3. Monitor real-time progress as each indicator is analyzed under rate-limit control.
4. View the consolidated triage table and click **Download Batch Results (CSV)** to import into your SIEM or SOAR platform.

---

## 9. Module 8: Interactive Correlation Network
Explore complex threat infrastructure:
1. Select **IOC Correlation Graph**.
2. Enter an indicator (e.g., `malicious-payload-cdn.net`).
3. An interactive Plotly network graph visualizes connected nodes:
   - **Nodes:** Domains, resolved IPs, hosted URLs, dropped hashes, and associated campaigns. Colored by risk category.
   - **Edges:** Verifiable relationship links (e.g., `RESOLVES_TO_IP`, `HOSTED_ON`, `ATTRIBUTED_TO`).
   - **Evidence Matrix:** A table below the graph provides explicit proof citations for every connection.

## 10. Module 9: Threat Monitoring & Watchlist
Maintain ongoing vigilance over high-risk artifacts:
1. Add an indicator to the watchlist.
2. The platform tracks baseline risk scores.
3. Click **Check Watchlist Now** (or trigger via API cron) to detect reputation shifts and alert on score increases $\ge 10$ points.

## 12. Module 11: Exporting Professional Threat Reports
Generate executive and technical dossiers:
1. Select one or more analyzed indicators from the selector.
2. Choose your format:
   - **PDF:** Executive dossier with color-coded risk badges, metric grids, evidence matrices, and defensive playbooks.
   - **JSON:** Complete raw telemetry dump for automated systems.
   - **CSV:** Formatted tabular triage list.
3. Click **Generate Report Dossier** and download the resulting file.

## 13. Module 12: Configuring Commercial API Keys
To connect VirusTotal, AbuseIPDB, URLhaus, or AlienVault OTX:
1. Create a `.env` file from `.env.example`:
   ```bash
   cp .env.example .env
   ```
2. Insert your personal or corporate API keys:
   ```env
   VIRUSTOTAL_API_KEY=your_key_here
   ABUSEIPDB_API_KEY=your_key_here
   URLHAUS_API_KEY=your_key_here
   ALIENVAULT_OTX_API_KEY=your_key_here
   ```
3. Restart the service. The **API Configuration** page will display green `READY` badges for all active providers.
